# Project Statement

## Problem statement

Students often have several assignments, tests, and study activities to remember. When this information is kept in different places, it can be hard to check due dates and know which work is still pending. The Student Study & Task Management System is a small desktop program that keeps this information together.

## Scope

The program supports student registration and login, task management, subject listing and entry, and a basic progress summary. It is intended as a local desktop application for an individual student account. It does not provide cloud storage, notifications, or collaboration between students.

## Target users

The intended users are school or college students who need a straightforward way to organize study-related tasks by subject and due date.

## High-level features

- Create an account and log in.
- Add, view, update, complete, and delete personal tasks.
- Add and view subjects.
- Review completed and pending task counts and completion percentage.
- Store the information in a local SQLite database.
